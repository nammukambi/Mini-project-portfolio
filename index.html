01 / Overview

What this project is about

Programmable analog gain systems focus on adjusting the amplification applied to an input signal. The goal of the design is to make signal amplitude controllable rather than relying on one fixed gain for every operating condition.

01 — INPUT

Receive a signal

An analog input enters the signal-conditioning stage. Its amplitude and source characteristics define the conditions the circuit must accommodate.

02 — CONTROL

Set the gain

The gain-setting network determines the relationship between the input and output amplitudes. A programmable design makes this setting selectable.

03 — OUTPUT

Deliver a conditioned signal

The amplified output should remain within the circuit's supply and component limits and be suitable for the next stage.

02 / Problem framing

Why controllable gain matters

A fixed-gain stage can be unsuitable when input levels vary: a small input may remain too small, while a large input may drive the output into clipping. The design challenge is to choose gain deliberately and verify that the output stays in a useful operating range.

Design challenge

Balance sensitivity and headroom

Higher gain improves the output level for small signals, but reduces the available input range before the amplifier reaches its output limits.

Design objective

Make gain selectable and testable

Define the intended gain settings, calculate the expected response, then compare the predicted values with measurements from the built circuit.

03 / Concept selection

From gain requirement to circuit

The core concept is an analog amplifier with a gain-setting network that can be changed to select different amplification levels. The final implementation should be selected against the required input range, output swing, bandwidth, noise, available supply rails and component constraints.

CONCEPT A

Fixed-gain amplifier

A simple baseline using a fixed feedback network. It is useful for establishing expected behavior and comparing later selectable-gain operation.

  • Simple to calculate and debug
  • One predetermined gain
CONCEPT B

Selectable-gain amplifier

A gain-setting network offers more than one gain choice. Switching may be implemented with a suitable analog switch or another validated selection method.

  • Supports multiple gain settings
  • Requires checking switch resistance, noise and settling behavior

These are the design alternatives for the artefact; the page does not claim that either circuit has passed hardware validation.

05 / Engineering basis

Gain calculation

For a non-inverting op-amp configuration, the ideal closed-loop voltage gain is set by the feedback resistor and the resistor from the inverting input to the reference node.

Aᵥ = 1 + Rf / Rg

Ideal non-inverting amplifier relation

Vout ≈ Aᵥ × Vin

Valid while the amplifier remains in its linear operating range

What to calculate

  • Target gain for each intended setting
  • Feedback and gain-setting resistor values
  • Expected output for minimum and maximum input
  • Output swing and bandwidth limits

What to account for

  • Supply voltage and amplifier output headroom
  • Input common-mode range and load
  • Resistor tolerance and amplifier non-idealities
  • Noise, stability and switching transients
06 / Verification plan

How the circuit should be checked

The verification sequence below is a test plan, not a claim of completed measurements. Record actual component values, instrument settings, observations and deviations when the hardware tests are performed.

1
Power and bias check

Confirm supply rails, reference levels and quiescent output before applying the test signal.

2
Small-signal gain check

Apply a known input amplitude and measure input and output using the same measurement convention.

3
Gain-setting check

Repeat for each available gain setting and compare measured gain with the calculated value.

4
Frequency and clipping check

Vary signal frequency and amplitude within the intended operating range; note bandwidth limits, distortion and clipping.

5
Repeatability and documentation

Repeat key measurements and document setup, readings, errors and any circuit changes.

07 / Engineering notebook

What to keep in the record

A useful project artefact connects the design decision to evidence. Keep calculations and observed results separate so the reader can tell what was predicted and what was measured.

DESIGN

Requirements & calculations

Record the intended gain range, signal conditions, circuit diagram, component values and the reasoning behind each selection.

BUILD

Implementation notes

Record the actual circuit configuration, wiring, supply conditions and any changes made while assembling the prototype.

EVIDENCE

Measurements & revisions

Attach oscilloscope captures or tabulated readings, compare them with predictions, and explain the next change using evidence.

08 / Reflection

Engineering is an iterative process

The key learning objective is to connect analog theory with practical behavior. Calculations establish expectations; bench measurements reveal the effects of real components, loading, bandwidth and supply limitations.

What a strong submission demonstrates

  • A clear, traceable design requirement
  • Correct calculations and circuit reasoning
  • Measurements tied to a repeatable setup
  • Evidence-based debugging and revision
